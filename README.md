# Some Old Mods for Minecraft: Pocket Edition
#### Self-explanatory.

- Some old mods I made back in 2016, when I was 14 years old, for Minecraft: Pocket Edition.
Made with JS.

### How it works

- Back in the day, modding for MCPE wasn't easy. Minecraft didn't had the easy navigation it have now, so if you wanted to play the game with mods, you could use _Blocklauncher_ or some other mod launcher.
- These mods where made to run with _Blocklauncher_, and all of them where wrote on *Javascript*.

## Mods:
### Harry Potter MCPE

- I was a fan of Harry Potter back in the day. This mod add some items and skins to the game.

### Marvel Universe mod

- Same thing as above, now with Marvel characters.
